# Bookworm: Online Book Store

Full-stack project with a separate client and server.

- client/  Next.js (App Router) + TypeScript + Tailwind
- server/  Node.js + Express + TypeScript + Prisma
- DB       PostgreSQL

## Phase 1: Setup + Book Categories

### 1. Database
Option A (Docker):
    docker compose up -d
Option B: use your own PostgreSQL and edit DATABASE_URL in server/.env

### 2. Server (http://localhost:5000)
    cd server
    cp .env.example .env
    npm install
    npx prisma migrate dev --name init
    npx prisma db seed
    npm run dev

Test it: http://localhost:5000/api/categories

### 3. Client (http://localhost:3000)
The client needs Next.js config files that are generated by create-next-app,
so create it first, then copy this zip's client files on top.

From the project root (the folder that contains server/):
    mv client client-src
    npx create-next-app@latest client --typescript --tailwind --app --eslint --no-src-dir --import-alias "@/*"
    cp -r client-src/app client-src/components client-src/lib client-src/.env.local.example client/
    rm -rf client-src
    cd client
    cp .env.local.example .env.local
    npm run dev

(When copying over the generated app/ folder, replace the existing files.)

Open http://localhost:3000

## API (Phase 1)
GET /api/health
GET /api/categories             list categories with book counts
GET /api/categories/:slug       one category with its books
GET /api/books?limit=4          latest books (max 50)
